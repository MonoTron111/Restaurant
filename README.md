Sistema de base de datos para la gestión de pedidos, mesas, empleados y menú de un restaurante. Permite registrar clientes, tomar pedidos por mesa, asignar meseros y cocineros a cada pedido, y controlar el inventario de ingredientes usados en cada plato.
